Selected Projects & Research

Web Scraping and LLMs: Comparing Methodologies for Extracting Unstructured Data · BSc thesis

Solo project · University of Bologna · Thesis (Italian · PDF)
  • Built SWEET, a benchmarking framework comparing LLM-based extraction techniques with classic rule-based scraping (using Italian transport strike notices as case study), across GPT, Gemini, Llama and DeepSeek.
  • Compared ways of cleaning unstructured HTML before it reaches the model, from raw and cleaned HTML to Markdown conversion and purpose-built small language models (Jina Reader, Dripper). DOM pre-filtering plus Markdown cut input tokens by 99.5% while keeping extraction accuracy (measured by F1 score) above 0.95.
  • Compared output validation schemes, finding that a flexible output normalised downstream in code, rather than a strict JSON schema, cut hallucinations by up to 45%.

JAnus · AI Accounting Engine

Freelance client project
  • Built the backend of a double-entry accounting engine for Italian VAT-registered freelancers: invoicing, VAT, payment schedules, cash flow and depreciation, with NestJS and Prisma on PostgreSQL in an Nx monorepo.
  • Built the LLM layer that drives the whole system from a chat, with function calling and structured output, turning plain-language requests into accounting operations. RAG is used to retrieve the information from the client's own invoices and receipts.

Qrami · Telemedicine Platform
