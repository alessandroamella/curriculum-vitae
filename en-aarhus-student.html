Selected Projects & Research

Web Scraping and LLMs: Comparing Methodologies for Extracting Unstructured Data · BSc thesis

Solo project · University of Bologna
  • Built SWEET (Semantic Web Extraction & Evaluation Tool), a benchmarking framework comparing LLM-based extraction against rule-based scraping across GPT, Gemini, Llama and DeepSeek over 1,400+ runs.
  • Showed a hybrid pipeline wins on semi-structured sources: deterministic DOM pre-filtering cut input tokens by 99.5% while holding the F1 score above 0.95.
  • Cut hallucinations by up to 45% by letting the model emit flexible output and normalising it downstream in code, instead of forcing a rigid schema on the model.
  • DOM mutation testing ("DOM chaos") showed LLM extraction stays robust where classic scrapers collapse, traded against latency, cost and silent rather than fail-fast errors.

JAnus · AI Accounting Engine

Freelance client project
  • Double-entry accounting engine for Italian VAT-registered freelancers: invoicing, VAT, payment schedules, cash flow and depreciation, in an Nx monorepo with a NestJS/Prisma backend on PostgreSQL and an Angular frontend.
  • The whole system is driven from a chat interface: an LLM layer with function calling and structured output turns plain-language requests into accounting operations, with RAG over the user's own documents.
