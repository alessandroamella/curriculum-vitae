Selected Projects

JAnus · AI Accounting Engine

Freelance client project
  • Double-entry accounting engine for Italian VAT-registered freelancers: invoicing, VAT, payment schedules, cash flow and depreciation, in an Nx monorepo with a NestJS/Prisma backend on PostgreSQL and an Angular frontend.
  • The whole system is driven from a chat via an LLM, with function calling and structured output, turning plain-language requests into accounting operations. RAG is used to retrieve the information from the client's own invoices and receipts.

Qrami · Telemedicine Platform

Freelance client project · qrami.it
  • Full telemedicine platform where doctors sign up, onboard onto Stripe Connect to get paid and set their own schedule, rates and coverage area; patients sign up and book a visit, and a matching algorithm picks the doctor by distance, availability and the patient's own ranking. Payments are handled end to end, automatically.
  • Visits are either video consultations, run through the Daily.co API to put doctor and patient in a call, or house calls. Every visit ends with a medical report and a fiscal receipt in the patient's dashboard.
  • Admin dashboard over the whole system with a full audit log, role-based access per user type, and GDPR handling for the health data involved. NestJS, Prisma, PostgreSQL with PostGIS, TanStack Start, on Google Cloud Run.

ezaffitto · Rental Listings Aggregator

Personal project · open source
  • Scraped rental listings for Bologna and Turin from five sources, Facebook groups included, and used OpenAI to normalise free-text ads into one queryable schema.
  • Dockerised microservices decoupled through RabbitMQ: one scraper per source (Puppeteer with stealth, async task queues), a concurrency-limited GPT parser with token counting, and a React web app with map search.

Web Scraping and LLMs: Comparing Methodologies for Extracting Unstructured Data · BSc thesis

Solo project · University of Bologna · Read the thesis (Italian · PDF)
  • Built SWEET (Semantic Web Extraction & Evaluation Tool), a benchmarking framework comparing LLM-based extraction with classic rule-based scraping on a real case (Italian transport strike notices), across GPT, Gemini, Llama and DeepSeek.
  • Compared ways of cleaning unstructured HTML before it reaches the model: raw HTML, cleaned HTML, Markdown conversion, and small language models built for the job (Jina Reader, Dripper), weighing extraction quality against token cost.
  • Compared output validation schemes, from strict JSON schemas to flexible output normalised downstream in code.
  • "DOM chaos" mutation tests on how LLM extraction and classic scrapers hold up when the page structure changes.
